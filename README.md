# Artemis Patch Manager — Android Edition

A lightweight, mobile‑optimized version of the Artemis Patch Manager designed for viewing, validating, organizing, and debugging PS3 patch files directly on Android. Built for creators who need fast patch management on the go while keeping full compatibility with the main desktop ecosystem.

---

## 📦 Overview

Artemis Patch Manager for Android brings the core patch‑handling workflow to mobile:

- Load and browse **Artemis patch files**
- Sort patches by **game version** (BLES, BLUS, NPUB, NPEB, etc.)
- Validate patch structure and metadata
- Identify broken or inconsistent codes
- Keep patch sets synced with your main Artemis workflow
- Designed for quick testing, reviewing, and fixing patches anywhere

This build mirrors the functionality of the main version while adapting the interface and workflow for Android devices.

---

## ✨ Features

- **Patch Viewer**  
  Browse patch files with clean formatting and fast navigation.

- **Version Sorting System**  
  Automatically groups patches by region/version so issues can be isolated quickly.

- **Metadata Handling**  
  Reads and displays patch metadata for easier debugging and organization.

- **Patch Validation**  
  Checks for malformed entries, missing fields, and structural inconsistencies.

- **Mobile‑Friendly UI**  
  Touch‑optimized layout designed for phones and tablets.

- **Creator‑Focused Workflow**  
  Built for patch developers who need to test, fix, and manage patches away from their desktop.

---

## 📁 File Support

Supports the same patch formats as the main Artemis Patch Manager:

- `patch.yml`
- `Imported_patch.yml`
- Multi‑version patch sets
- Metadata‑rich patch structures
- Region‑specific patch groups (BLES, BLUS, NPUB, etc.)

Full compatibility ensures patches behave the same across desktop and Android.
